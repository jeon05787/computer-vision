# Computer Vision Projects & Lab Notes 👁️

## 📌 주요 특징 (Key Features)

- **영상 처리 기초**: Filtering, Edge Detection, Morphological Operations, Color Spaces
- **특징 추출 & 매칭**: Corner Detection, Feature Extraction (SIFT, SURF, ORB 등)
- **딥러닝 기반 비전 모델**: Image Classification, Object Detection, Semantic Segmentation
- **실습 환경 및 예제**: OpenCV, PyTorch 기반 실행 가능한 Jupyter Notebook 및 스크립트 구성

##  실행 가이드 (How to Run)

각 디렉토리 내부의 Jupyter Notebook(`.ipynb`) 또는 Python 스크립트(`.py`)를 실행하여 결과를 확인할 수 있습니다.

